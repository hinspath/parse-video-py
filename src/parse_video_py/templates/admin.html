Admin控制台

这里集中管理全局 Cookie、下载代理开关和失败域名记录。普通用户自己的 Cookie 只保存在用户浏览器，不会写入这里。

敏感操作只使用管理员密码提交，不需要把 API Token 放在前端页面。

全局平台 Cookies

用户没有设置自己的 Cookie 时，后端会使用这里保存的全局 Cookie。当前抖音已接入；其它平台先保存，后面解析器接入后直接启用。留空表示保持原值，输入 CLEAR 表示清空该平台。
